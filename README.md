# Chinese Parents Skill

> 中国式家长行为模拟与诊断框架。基于 **10 维组合系统**覆盖中国式家长的全部行为变体，支持**模拟模式**和**诊断模式**双模式运作。

[English](README-EN.md)

---

## 概述

中国式家长并非单一模式。**本框架用 10 个独立维度描述家长行为差异**，每个维度 3-4 个档位，理论上可覆盖 3^10 ≈ 59049 种家长形态。

### 核心能力

| 模式 | 用途 | 示例 |
|------|------|------|
| **模拟模式** | 按维度组合生成家长行为反应 | "用虎妈但温度调高，我考了第三" |
| **诊断模式** | 反向分析家长类型 | "帮我分析一下我妈是什么家长" |

## 10 维家长画像系统

| # | 维度 | 核心问题 | 档位 |
|---|------|---------|------|
| 1 | **控制** | 管得多宽？ | 放任 ← 适度 → 严格 → 控制 |
| 2 | **温度** | 情感是暖是冷？ | 冷漠 ← 理性 → 温暖 → 溺爱 |
| 3 | **参与** | 投入了多少精力？ | 缺席 ← 被动 → 主动 → 过度介入 |
| 4 | **焦虑** | 对未来有多焦虑？ | 佛系 ← 适度 → 焦虑 → 恐慌 |
| 5 | **沟通** | 怎么跟孩子说话？ | 命令 ← 说教 → 商量 → 倾听 |
| 6 | **观念** | 思想开明还是保守？ | 传统保守 ← 混合 → 开明现代 |
| 7 | **经济** | 给钱的方式和态度？ | 苛刻 ← 适度 → 慷慨 |
| 8 | **期望** | 对孩子期望多高？ | 无要求 ← 适度 → 极高 |
| 9 | **社交** | 怎么管孩子社交？ | 封闭 ← 引导 → 开放 |
| 10 | **独立** | 培养还是包办？ | 包办 ← 引导 → 放手 |

## 使用方法

### 模拟模式

三种方式指定维度组合：

```
# 口语化描述（推荐）
"我妈管我管得特别严，但对我特别好"
→ 控制:严格 + 温度:温暖

# 参考类型修改
"像虎妈，但温度调高一点"

# 直接指定
"控制:严格 + 温度:温暖 + 焦虑:焦虑 + 沟通:商量"
```

### 诊断模式

描述家长行为即可：

```
"帮我分析一下我妈是什么类型的家长"
"我妈总是这样，她到底是什么心理？"
```

AI 会自动追问补充信息，然后生成诊断报告。

### 输出格式

模拟模式：

```
【家长画像】
  控制: 严格 | 温度: 温暖 | 参与: 主动
  焦虑: 焦虑 | 沟通: 命令 | 观念: 传统
  经济: 适度 | 期望: 极高 | 社交: 封闭
  独立: 包办

【场景】xxx
【角色状态】xxx
【对话】xxx
【内心OS】xxx
```

诊断模式：

```
┌──────────────────────────────────────┐
│       中国式家长类型诊断报告            │
└──────────────────────────────────────┘
【维度画像】10 维可视化评分
【参考类型】最接近的已知类型
【典型场景预测】基于维度组合的行为预测
【建议沟通方式】针对性沟通策略
```

## 10 大场景

| 场景 | 触发词 | 关键维度 |
|------|--------|---------|
| 学业/工作 | 考试、分数、绩效、升职 | 控制、温度、焦虑、期望、沟通 |
| 人生选择 | 辞职、创业、转行、gap year | 观念、控制、焦虑、温度、沟通 |
| 婚恋关系 | 恋爱、相亲、结婚、不婚 | 观念、社交、控制、温度 |
| 消费经济 | 花钱、买、贵、工资、存钱 | 经济、控制、观念 |
| 家庭相处 | 打电话、回家、过节 | 温度、参与、沟通 |
| 社交交友 | 朋友、出去玩、聚会 | 社交、控制、独立 |
| 网络电子产品 | 游戏、手机、上网、熬夜 | 控制、焦虑、沟通 |
| 健康生活习惯 | 吃饭、睡觉、运动、减肥 | 温度、控制、参与 |
| 外表形象 | 穿着、打扮、化妆、纹身 | 观念、控制 |
| 教育方式 | 择校、兴趣班、留学、学区房 | 焦虑、经济、期望、参与 |
