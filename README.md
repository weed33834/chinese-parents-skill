## 简介

你妈说过"你看看人家孩子"吗？

你妈会在你考了第三名之后先夸两句，再问"那第一名多少分"吗？

你妈是虎妈、鸡娃妈、还是佛系妈？

这个项目不做理论研究，只做一件事：**让 AI 模拟你家那位的语气、逻辑和内心戏。**

它能干两件事：

- **模拟** —— 告诉它你妈是什么样的人，它演给你看
- **诊断** —— 描述你妈的行为，它帮你分析你妈到底属于哪种类型

中国式家长不是单一模式。同一个"考了第三名"，有的妈先骂再问，有的妈先夸再问，有的妈根本不问。10 个维度组合，理论上覆盖 **59049 种家长形态**。你妈大概率在里面。

## 10 个维度，拆穿中国式家长

不是所有妈都一样。这 10 个维度决定了你妈和别人的妈有什么不同：

| 维度 | 管什么 | 档位 |
|------|--------|------|
| 控制 | 管得多宽 | 放任 · 适度 · 严格 · 控制 |
| 温度 | 情感是暖是冷 | 冷漠 · 理性 · 温暖 · 溺爱 |
| 参与 | 投入了多少精力 | 缺席 · 被动 · 主动 · 过度介入 |
| 焦虑 | 对未来有多焦虑 | 佛系 · 适度 · 焦虑 · 恐慌 |
| 沟通 | 怎么跟孩子说话 | 命令 · 说教 · 商量 · 倾听 |
| 观念 | 思想开明还是保守 | 传统 · 混合 · 开明 |
| 经济 | 给钱的方式和态度 | 苛刻 · 适度 · 慷慨 |
| 期望 | 对孩子期望多高 | 无要求 · 适度 · 极高 |
| 社交 | 怎么管孩子社交 | 封闭 · 引导 · 开放 |
| 独立 | 培养还是包办 | 包办 · 引导 · 放手 |

## 怎么玩

### 模拟你妈

三种方式，随便用哪种：

```
# 1. 大白话（推荐）
"我妈管我管得特别严，但对我特别好"
→ 自动映射为 控制:严格 + 温度:温暖

# 2. 在参考类型上改
"像虎妈，但温度调高一点"

# 3. 直接指定维度
"控制:严格 + 温度:温暖 + 焦虑:焦虑 + 沟通:商量"
```

### 诊断你妈

描述你妈的行为，AI 帮你分析：

```
"帮我分析一下我妈是什么类型的家长"
"我妈总是这样，她到底是什么心理？"
```

AI 会追问补充信息，然后生成一份诊断报告。

### 同一件事，不同的妈

同一个"辞职去创业"，不同维度的妈反应天差地别：

<details>
<summary>点开看 → 控制型妈 vs 民主型妈</summary>

**控制:控制 + 观念:传统 + 温度:冷漠**
```
"不行。我已经托人给你找好了单位，下周一去报到。
 创业？你见过几个创业成功的？"
（内心OS：害怕孩子失败，但绝不表达为担忧，只表达为愤怒。）
```

**控制:适度 + 观念:开明 + 温度:温暖**
```
"这个决定挺大的，能跟我说说你是怎么想的吗？"
（认真听完）
"创业确实有风险，但年轻的时候试错成本低。
 你做了市场调研吗？需要爸妈帮忙的地方说一声。"
（内心OS：担心得一晚上睡不着，但知道孩子长大了，不能拦着。）
```
</details>

## 经典语录速查

你妈说过哪几句？

```
□ "我都是为你好"                    → 温度:理性
□ "你看看人家XXX"                  → 期望:极高
□ "等你当父母就知道了"              → 沟通:说教
□ "要不是为了你，我早就……"          → 温度:理性 + 控制:控制
□ "你只要好好学习就行了，其他不用管" → 期望:极高 + 独立:包办
□ "几点回来？跟谁出去？男的还是女的？" → 控制:严格
□ "钱够不够？妈给你转点？"          → 经济:慷慨 + 温度:温暖
□ "完了完了，这可怎么办！"          → 焦虑:恐慌
□ "你自己看着办吧"                  → 控制:放任
□ "别跟那些不三不四的人玩"          → 社交:封闭
```

选中的越多，对应维度的档位越突出。

## 10 大场景

每个场景下，不同维度档位会让回应完全不一样。完整规则见 [SKILL.md](SKILL.md)。

**A 学习/工作** —— 考试砸了、涨薪了、想辞职了
关键维度：控制 · 焦虑 · 期望 · 沟通 → 决定了你妈是先骂还是先问

**B 人生选择** —— 辞职、创业、转行、gap year
关键维度：观念 · 控制 · 焦虑 → 决定了你妈是支持还是拦着

**C 婚恋** —— 没对象急、有对象挑、不结婚不行
关键维度：观念 · 社交 · 控制 → 决定了你妈是催婚还是开明

**D 花钱** —— 买了件贵衣服、月光了、想借钱给朋友
关键维度：经济 · 控制 → 决定了你妈是"该花就花"还是"败家子"

**E 家庭相处** —— 打电话、回家、过节
关键维度：温度 · 参与 · 沟通 → 决定了你妈是唠叨还是不搭理你

**F 社交交友** —— 朋友、出去玩、聚会
关键维度：社交 · 控制 → 决定了你妈是审查朋友还是放你出去

**G 手机/网络** —— 游戏、刷视频、熬夜
关键维度：控制 · 焦虑 → 决定了你妈是到点收手机还是不管

**H 健康习惯** —— 吃饭、睡觉、运动、减肥
关键维度：温度 · 参与 → 决定了你妈是做营养餐还是不管你

**I 外表形象** —— 穿着、打扮、化妆、纹身
关键维度：观念 · 控制 → 决定了你妈是尊重审美还是管你穿什么

**J 教育择校** —— 择校、兴趣班、留学、学区房
关键维度：焦虑 · 经济 · 期望 → 决定了你妈是砸钱鸡娃还是随缘
