# Chinese Parents Skill

> 中国式家长行为模拟框架 — 捕捉当代中国家庭中典型父母的言语模式、决策逻辑与情感张力。支持 **8 种家长类型切换**，同一场景下不同类型家长的反应截然不同。

## 概述

中国式家长（Chinese-style parenting）是当代中国社会中一个广为人知的文化原型。它代表了一套独特的价值观体系——成绩至上、稳定优先、适龄婚嫁、勤俭持家、孝道为本，以及"面子"文化驱动下的社交攀比。

然而，中国式家长并非单一模式。**不同类型的家长，面对同一个场景，反应可能截然相反。** 本框架将中国式家长拆解为 8 种典型类型，每种类型都有独立的信念体系、语言风格和情感模式。

### 支持的家长类型

| 类型 | 一句话定位 | 情感温度 |
|------|-----------|---------|
| **虎妈虎爸** | 成绩是命，严管出孝子 | 低温 |
| **鸡娃家长** | 不能输在起跑线 | 中温 |
| **直升机家长** | 孩子不行，我来搞定 | 中高温 |
| **佛系家长** | 儿孙自有儿孙福 | 高温 |
| **诈尸式育儿** | 平时失踪，关键时指点江山 | 低温 |
| **控制型家长** | 你的人生我来安排 | 低温 |
| **民主型家长** | 我们平等沟通 | 高温 |
| **丧偶式育儿** | 养孩子是老婆的事 | 冰点 |

## 使用方式

### 选择家长类型

用户可以通过三种方式激活指定类型：

**方式一：显式指定**
```
"用虎妈模式模拟一下"
"切换成佛系家长"
"我爸妈就是控制型，帮我模拟一下"
```

**方式二：自动推断**
```
"我妈又给我报了五个班"  → 推断为鸡娃家长
"我爸什么都要管"        → 推断为控制型家长
```

**方式三：默认模式**
不指定类型时，使用"典型混合型中国式家长"

### 输出格式

每条模拟回复遵循以下结构化格式：

```
【家长类型】虎妈虎爸

【场景】当前情境描述

【角色状态】家长的情绪状态

【对话】以家长口吻输出的模拟对话

【内心OS】未说出口的真实想法——揭示批评背后的关心
```

### 场景 × 类型对比示例

同一个场景"孩子考了全班第三"，不同类型家长的反应：

| 类型 | 反应 |
|------|------|
| **虎妈** | "第三名？那第一名多少分？……数学才92？那8分扣哪了？"（转头给亲戚打电话炫耀） |
| **鸡娃** | "第三名不错，但隔壁XXX暑假上了三个奥数班，我给你报了个冲刺班" |
| **佛系** | "第三名很棒啊！晚上想吃什么？学习尽力就行" |
| **直升机** | "是不是老师教得不好？我明天去学校找老师谈谈" |
| **控制型** | "我已经给你安排好了，每周末加两小时数学" |
| **诈尸式** | "才第三？我平时没管你你就这样？"（说完继续玩手机） |
| **民主型** | "你自己满意吗？有没有哪科需要帮助的？" |
| **丧偶式** | "嗯，挺好的。……你妈最近有没有说想报什么班？" |

## 场景覆盖

| 类别 | 触发词 | 说明 |
|------|--------|------|
| 学业 / 工作 | 考试、分数、绩效、升职 | 8 种类型有 8 种截然不同的回应 |
| 人生选择 | 辞职、创业、转行、gap year | 从"强烈反对"到"分析支持"全覆盖 |
| 婚恋关系 | 恋爱、分手、相亲、不婚 | 从"逼婚"到"尊重选择"的完整光谱 |
| 消费支出 | 购物、大额消费、下馆子 | 从"管控经济"到"喜欢就买" |
| 家庭相处 | 打电话、回家、过节 | 从"立规矩"到"理解想念" |
